Maqueen 시뮬레이터 사용법

    

      

        
코딩

        
    
          
  • 블록: MakeCode 스타일 블록으로 코딩합니다. 코드 미리보기로 변환된 JavaScript · MicroPython 을 볼 수 있습니다.
    • 
          
  • JavaScript: MakeCode JavaScript(basic, input, maqueen, neopixel …)를 직접 작성합니다.
    • 
          
  • MicroPython: from microbit import *, maqueen, music, neopixel, machine, utime 모듈을 사용할 수 있습니다.
    • 
          
  • 블록 → 텍스트 탭으로 이동하면 블록 코드가 변환됩니다. (텍스트 → 블록 변환은 지원하지 않습니다)
    • 
          
  • Ctrl+Enter 실행, 작업 내용은 브라우저에 자동 저장됩니다.
    • 
        

        
시뮬레이션

        
    
          
  • 마우스 드래그: 시점 회전 · 휠: 확대/축소 · 오른쪽 드래그: 이동
    • 
          
  • 로봇 드래그: 위치 이동 · Shift+드래그: 방향 회전
    • 
          
  • 키보드 A, B: micro:bit 버튼, S: 흔들기 (편집기 밖에서)

마퀸(ROB0148) 연결 정보

        

          
장치연결비고

          
모터 M1(왼쪽) / M2(오른쪽)I2C 0x10레지스터 0x00 / 0x02 ← [방향, 속도]

          
라인 센서 왼쪽 / 오른쪽P13 / P14검은 선 = 1, 흰 바닥 = 0

          
초음파 센서P1(Trig) / P2(Echo)거리(cm) = 펄스(us) ÷ 58

          
빨간 LED 왼쪽 / 오른쪽P8 / P12디지털 출력

          
RGB LED ×4P15네오픽셀 (WS2812)

          
부저P0music 모듈

          
IR 수신기P16NEC 리모컨

          
서보 S1 / S2I2C 0x10레지스터 0x14 / 0x15 ← [각도]

maqueen.motor_run(maqueen.ALL, maqueen.CW, 150)
maqueen.motor_stop()
maqueen.ultrasonic()          # cm
maqueen.read_patrol(maqueen.LEFT)
maqueen.write_led(maqueen.RIGHT, 1)
maqueen.servo_run(maqueen.S1, 90)
maqueen.ir_read()
